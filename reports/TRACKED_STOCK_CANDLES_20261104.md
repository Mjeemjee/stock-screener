# 跟踪股票 K 线交付说明

日期：2026-11-04，香港时间。

## 你会看到什么

进入「追踪」→「逐期结果」→「查看股票 / K线」→ 点击股票。也可以从「自选」点击股票。

| 新增内容 | 用最简单的话说明 |
|---|---|
| 日 K 线 + 独立成交量栏 | 看一天里怎样开盘、最高到哪、最低到哪、怎样收盘，以及成交量 |
| 1 / 3 / 6 / 12 个月、缩放和拖动 | 看近处细节或更长的走势；实际范围受已有数据限制 |
| 选择跟踪期 | 同一股票在不同日期、不同策略、不同持有期，分别查看 |
| 蓝色买入、棕色卖出箭头 | 对照模拟跟踪记录；预计将来的卖出不当成已经卖出 |
| 日线价格表 | 不看图也能逐天核对开、高、低、收和成交量 |
| 异常及缺失提示 | 缺价格不编造；原始异常日线排除并告知；买卖价与开盘价不一致时隐藏对应箭头 |

## 数据与原有策略的关系

- 每股按需加载，最多 260 根已收盘日线；没有使用实时、盘中数据。
- 优先沿用跟踪计算所用的整段历史源；不把不同复权来源拼接。
- 可在免费行情源补数，每轮最多 4 只，优先最新一期最终组合。补数保存在 `data/screening_archive/chart_prices/`，原策略不读取此目录。
- 本次没有修改 `screener/`、选股参数、收益计算、冻结档案、研究策略或 DeepSeek 决策规则。
- 复权价格不是当年未复权报价。成交量保留源单位，不能直接假定都是股数。
- 本机复核线上 2026-11-03 20:17 UTC 档案：657 只历次候选中，373 只有可展示日线、284 只仍缺日线；最新一期最终组合 44 只均可展示。覆盖数会随每日档案变化。
- 公网逐股核对 44/44 可用，各股截至 2026-11-02 或 2026-11-03，以页面逐股日期为准。

## 怎么验证

1. 打开某一期跟踪股票，检查「K线跟踪期」与点击的日期、策略和持有期一致。
2. 查看日线表，核对买卖日的开盘价与模拟记录。只有相符的实际模拟买卖日才有箭头。
3. 切换显示范围、拖动、缩放；手机端横向滑动价格表，不应撑宽整页。
4. 缺失数据、异常价格、复权不一致、网络错误和重试均应有明确状态。

本地验证：136 项原后端回归、10 项图表导出测试、6 项发布白名单/隔离测试、30 项前端测试、生产类型检查和构建通过；11 项新浏览器场景及 8 项原跟踪场景通过。浏览器覆盖桌面与 320/390/768 像素宽度、真实数据及受控异常数据，无写请求或未捕获错误。

复现入口：`scripts/test_export_chart_history.py`、`portfolio-board/src/lib/candles.test.cjs`、`portfolio-board/scripts/verify-candles-browser.cjs`、`portfolio-board/scripts/verify-tracking-browser.cjs`。本地证据在 `reports/candles-20261104/`，公开构建继续受白名单和图表字段校验保护。

这些验证证明展示功能与记录的对应关系，不证明选股策略有超额收益。
